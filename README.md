# open-beeper

Statische Weiterleitung auf `beeper://` (GitHub Pages). Grund: Die Claude-App auf dem iPhone lässt nur https-Links durch, keine App-Schemata. Die Arbeitsfläche [Inbox Digest](https://github.com/martinschimak/inbox-digest) verlinkt auf dem iPhone hierher, die Seite öffnet Beeper. Enthält keine Daten.
