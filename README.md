# open-beeper

Statische Weiterleitung auf App-Links (GitHub Pages): ohne Parameter `beeper://`, mit `?u=` ein `message:`-Link (Apple Mail) oder `beeper:`-Link. Grund: Die Claude-App auf dem iPhone lässt nur https-Links durch, keine App-Schemata. Die Arbeitsfläche [Inbox Digest](https://github.com/martinschimak/inbox-digest) verlinkt auf dem iPhone hierher, die Seite öffnet Beeper bzw. die Mail in Apple Mail. Enthält keine Daten.
